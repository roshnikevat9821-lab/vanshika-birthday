# Vanshika's Birthday Website

A static birthday surprise site published with GitHub Pages.

## Publish with GitHub Pages

1. Create a **public** repository named `vanshika-birthday` on GitHub.
2. Extract this ZIP. Upload the *contents* of this folder to the repository root (so `index.html` is at the top level, beside `assets/`). Do not upload the ZIP itself.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the Pages deployment to finish. The expected site URL is `https://roshnikevat9821-lab.github.io/vanshika-birthday/` if the repository owner is `roshnikevat9821-lab` and the repository name is `vanshika-birthday`.

## Before sharing

- Test the birthday gate, card, music player, photos, and wish submission at the published URL.
- Test a wish and confirm it appears in the `Wishes` tab of the `Vanshika Wishes` Google Sheet.
- Keep the Google Sheet itself private.
- GitHub Pages is public for a public repository on GitHub Free. The website and uploaded photos/music may be viewed by anyone who has the URL (and potentially discovered by others). Do not put passwords, private data, or secrets in this repository.

## Wish collection

The site is configured with the supplied Google Apps Script `/exec` endpoint. The backend code and setup notes are in `apps-script/`.
